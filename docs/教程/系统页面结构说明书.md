# ERP 系统页面结构说明书

> 依据 `src/router/index.js`（路由注册）与 `src/router/menus.js`（侧边栏）整理。  
> 便于按模块定位页面：路由路径 → 页面标题 → Vue 文件。  
> 各模块 `*/overview` 共用 `src/views/flow/ModuleFlowView.vue`（流程图 / 概述页）。

**相关文件**

| 用途 | 路径 |
|------|------|
| 路由定义 | `src/router/index.js` |
| 侧边栏菜单 | `src/router/menus.js` |
| 主布局 | `src/layouts/MainLayout.vue` |
| 模块概览页 | `src/views/flow/ModuleFlowView.vue` |
| 占位页 | `src/views/common/PlaceholderView.vue` |

## 速查：按 views 目录找页面

```text
src/views/
├── login/          登录
├── dashboard/      首页
├── error/          404
├── flow/           各模块 overview（共用）
├── common/         占位页等
├── basic/          基础资料（含 supplier / customer / inventory）
├── stock/          库存
├── purchase/       采购
├── sales/          销售
├── cash/           往来现金
├── project/        工程
├── plan/           计划
├── production/     生产
├── quality/        质量
├── hr/             人力
├── oa/             办公 OA
├── accounting/     会计财务
├── report/         报表 / 看板
└── system/         系统管理
```

**约定**

1. 业务页多在 `src/views/<模块>/`，路由在 `src/router/index.js` 用懒加载注册。  
2. 侧边栏结构见 `src/router/menus.js`（菜单可不含 overview，但路由有）。  
3. 模块根路径 `meta.isModuleRoot: true`，默认 `redirect` 到 `/{module}/overview`。  
4. 流程图定制与概述见同目录 [`模块流程图开发说明.md`](./模块流程图开发说明.md)。
