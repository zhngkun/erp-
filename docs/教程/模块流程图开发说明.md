# ERP 模块流程图开发说明

> 给后续开发 / Agent 阅读：如何为侧边栏父级菜单增加或定制流程图页。  
> LogicFlow 官方能力与 Agent Rules 见同目录 [`流程图说明.md`](./流程图说明.md)。

侧边栏**父级菜单**点击后，除展开子菜单外，还会打开该模块的流程图概览页（如 `/stock/overview`）。  
库存管理已定制；其他模块未定制时会按子菜单自动生成简易从左到右流程图。

## 已实现能力

| 能力 | 说明 |
|------|------|
| 父级点击开页 | `AppSidebar` 点击父级 → `/{module}/overview` |
| 路由 | 各业务模块已有 `overview` 子路由，`redirect` 指向 overview，`meta.isModuleRoot: true` |
| 画布 | LogicFlow 只读展示，长方形节点 + 箭头 + 沿箭头方向流动的虚线 |
| 节点点击 | `properties.path` 有值则 `router.push` 进业务页 |
| 定制 / 兜底 | `customFlowcharts` 有配置用定制图，否则 `buildAutoFlowchart` |

## 目录结构

```
src/components/flow/
  LogicFlowBoard.vue      # 画布封装（尺寸、主题、流动 CSS）
  registerFlowEdge.js     # 自定义节点 flow-rect、边 flow-edge

src/views/flow/
  ModuleFlowView.vue      # 所有模块共用的 overview 页面

src/config/flowcharts/
  helpers.js              # flowNode / flowEdge / defineFlowchart
  index.js                # 注册表 customFlowcharts + 自动生成
  stock.js                # 库存管理定制流程（范例）
```

## 如何给新模块加定制流程图

以「采购管理」`/purchase` 为例，**一般只需改配置，不必改路由/侧边栏**（overview 路由已统一加好）。

### 1. 新建数据文件

复制库存范例，新建 `src/config/flowcharts/purchase.js`：

```js
import { defineFlowchart, flowEdge, flowNode } from './helpers'

// 建议：列 x 间隔约 240，行 y 间隔约 100；布局从左到右
const COL = { left: 140, mid: 380, right: 620 }

export const purchaseFlowchart = defineFlowchart(
  '采购管理流程',
  [
    flowNode({ id: 'plan', text: '采购计划', x: COL.left, y: 120, path: '/purchase/plan' }),
    flowNode({ id: 'order', text: '采购订单', x: COL.mid, y: 120, path: '/purchase/order' }),
    flowNode({ id: 'inbound', text: '采购入库', x: COL.right, y: 120, path: '/purchase/inbound' }),
    // path: null 表示仅展示、不可跳转
  ],
  [
    flowEdge({ id: 'e1', source: 'plan', target: 'order' }),
    flowEdge({ id: 'e2', source: 'order', target: 'inbound' }),
  ],
)
```

### 2. 登记到注册表

编辑 `src/config/flowcharts/index.js`：

```js
import { purchaseFlowchart } from './purchase'

export const customFlowcharts = {
  '/stock': stockFlowchart,
  '/purchase': purchaseFlowchart, // 新增
}
```

`key` 必须与 `src/router/menus.js` 里该父级的 `path` 一致（如 `/sales`、`/basic`）。

### 3. 验证

1. 登录后点击侧边栏对应父级（如「采购管理」）
2. 应打开「采购管理流程」页，连线带箭头且虚线沿箭头流动
3. 点击有 `path` 的节点应进入对应业务页

## 数据约定

### 节点 `flowNode`

| 字段 | 含义 |
|------|------|
| `id` | 唯一，边的 source/target 引用它 |
| `text` | 显示文案 |
| `x` / `y` | 中心坐标，**从左到右**排布 |
| `path` | 跳转路由；无跳转传 `null` |

实际渲染尺寸由画布统一为 **160×36** 长方形，无需在数据里写宽高。

### 边 `flowEdge`

| 字段 | 含义 |
|------|------|
| `id` | 唯一 |
| `source` / `target` | 起点、终点节点 `id` |

边类型固定为 `flow-edge`（helpers 已写好）。

## 样式与动画注意（踩坑）

1. **节点尺寸**：LogicFlow 主题里的 `rect.width/height` **不会**改变模型尺寸；本项目在 `LogicFlowBoard` 里强制写入 `properties` + 自定义 `flow-rect`。
2. **流动方向**：不要依赖内置 `animationDirection`（SVG 上常不生效）。流动由 `LogicFlowBoard.vue` 中 CSS `@keyframes erp-flow-dash` 控制；`stroke-dashoffset` 往**负**方向 = 沿箭头流向。若方向反了，把 `to` 的偏移改成正值。
3. **箭头**：自定义边视图必须给折线挂上 `markerEnd`（见 `registerFlowEdge.js`），否则箭头会消失。
4. **keep-alive**：进入 overview 会重建画布，避免缓存旧实例导致样式不更新。

## 若某模块还没有 overview 路由

正常业务模块已批量加过。若新建顶级模块，在 `src/router/index.js` 中需要：

```js
{
  path: '/xxx',
  name: 'Xxx',
  component: Layout,
  redirect: '/xxx/overview',
  meta: { title: '某某管理', icon: '...', isModuleRoot: true },
  children: [
    {
      path: 'overview',
      name: 'XxxOverview',
      component: () => import('@/views/flow/ModuleFlowView.vue'),
      meta: { title: '某某管理流程' },
    },
    // ...业务子路由
  ],
}
```

侧边栏父级点击逻辑在 `AppSidebar.vue` 的 `onParentClick` → `getModuleOverviewPath`。

## Agent 后续改流程图时

1. 先读本文 + 对照 `src/config/flowcharts/stock.js`
2. 优先只改 `src/config/flowcharts/*` 与 `customFlowcharts` 注册
3. 不要重复造画布组件；样式/动画问题优先查「样式与动画注意」
4. LogicFlow API 细节查本地 `node_modules/@logicflow/core` 文档（见 [`流程图说明.md`](./流程图说明.md)）
